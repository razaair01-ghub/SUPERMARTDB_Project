## 📦 Project Overview  
This repository contains **multiple analytics projects** built using **SQL + Power BI** on the **Supermart Retail Dataset (~50K records)**.  
Each project focuses on a different business area — customers, products, delivery, regional profitability, and time-series performance.

This repo demonstrates:  
- SQL data exploration  
- KPI engineering  
- Trend analysis (MoM, YoY)  
- Customer segmentation  
- Discount & profitability analysis  
- Delivery performance insights  
- Power BI dashboard creation  
- Business intelligence storytelling  

---

## 🗂️ Dataset Summary  
The **Supermart Retail Dataset** includes:

- Orders → OrderDate, ShipDate, Sales, Profit, Quantity, Discount  
- Customers → Region, Segment, Demographics  
- Products → Category, Sub-Category, Price  
- Shipping → Delivery time, Mode, Regions  
- Perfect for **business intelligence, segmentation, forecasting, and retail analytics**
